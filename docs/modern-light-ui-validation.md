# 浅色工作台界面改造验证

日期：2026-11-02。完成 C++20 / Qt 6 Widgets 界面改造，构建输出为 `build/DiskCleaner.exe`。

## 实际改动

- 暖白和白色表面、炭黑主按钮、低饱和强调色；统一正文、摘要、表头和辅助信息层次。
- 扫描类型与统计口径采用共用底座的分段选择，数据行仍为 26 逻辑像素。
- 应用操作采用自行绘制的线性图标；下拉、展开、勾选等指示器使用内置 SVG，新增 Qt Svg 构建依赖，无第三方组件库。
- 按钮、输入框、下拉、数字输入、复选/单选、列表勾选、菜单、滚动条、停靠面板、提示和弹窗使用统一主题规则，保留焦点、禁用与选中状态。
- 列表使用轻表头、无网格线表格、6px 占比条；空间图采用柔和分类色，实际面积算法不变。
- 路径缩略显示为面包屑，菜单可返回祖先目录和复制完整路径。祖先跳转按路径重新解析，避免实时更新压缩节点编号后跳错位置。
- 图表层级与分类配色收进右上角选项，原有快捷键仍生效。支持在浮层中用键盘更改层级。
- 导出、多位置选择等对话框统一间距和主按钮；扫描、导入导出、实时更新及删除业务逻辑保持原实现。
- 为保留用户熟悉的入口，最终保留文件/选项/帮助菜单栏及关于页；没有新增侧栏或对话输入框。Windows 标题栏和系统文件选择器继续由系统负责。
